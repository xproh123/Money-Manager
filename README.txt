Money Manager

A simple personal finance tracker built with Flask and SQLite.

Features
--------
- User registration and login
- Password hashing
- Session-based authentication
- Add earnings and expenses
- Search transactions by keyword
- Filter transactions by type and date range
- Sort transactions by date or amount
- Monthly earnings and expense summary

Tech Stack
----------
- Python
- Flask
- SQLite
- Jinja2
- Bootstrap

Purpose
-------
This project was created to help users record and review their earnings and expenses. It focuses on tracking financial activities and spending habits through filtering, searching, and monthly summaries.
This project does not have balance, as it is meant for people to track their spending habit and see how much they have earned, not wealth management. (Also some people do not want to disclose their wealth.)
